# 文件系统安全

适用范围：修改扫描、挂载、卸载、同步、删除或回滚逻辑时。

## 规则

- 写操作和递归删除必须通过 Jail 路径检验，严格限制在目标项目 `.agents/skills` 内，不得触碰项目源码或系统路径。
- 中央仓库是只读权威原件池；除 `git pull` 同步以及经过用户显式确认并自动执行快照备份的反向更新（Push）外，禁止直接写入或删除。写入时必须通过 Jail 路径检验，限制在 `skills/<skill_name>` 内。
- 挂载路径被占用时必须让用户确认；默认将原对象移入 `.backup`，禁止静默覆盖。
- 批量操作必须使用操作日志支持两阶段原子回滚；任一步失败时逆向恢复，禁止遗留孤儿链接。
